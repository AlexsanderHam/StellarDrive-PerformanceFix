# Performance Fix

A performance optimization mod for **StellarDrive** designed to eliminate stutters, save lags, and frame drops.

## 🌟 Features

- **Asynchronous Save System**: Moves heavy JSON serialization and file writing to a background task, completely eliminating the single-digit frame drops during auto-saves and manual saves.
- **Stutter & Lag Fixes**: Optimizes major bottlenecks to keep your gameplay and building smooth even in large-scale worlds.

## 📥 Installation

This mod can be installed and managed using [StellarModManager](https://github.com/jollyname/StellarModManager). Simply launch the manager, find **Performance Fix** in the list, and click install!
